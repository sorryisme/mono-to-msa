## 변경 내용

### `docs/todo/260914-부하-테스트-자동화.md`

- 머리말 상태를 `부분 완료` → `기본 범위 완료` 로 바꾸고, 범위 검토 반영 사실을 갱신일 항목으로 추가했다.
- "도입 순서" 의 1·2차를 `(기본)`, 3차를 `(선택 확장)` 으로 표시하고, 선택 확장을 하지 않아도 미완료가 아니라는 문장을 넣었다.
- "현재 구성 점검" 제목에 최초 점검일(2026-09-14)을 명시하고, 그 아래 "점검 이후 변경 (2026-09-18 기준)" 절을 새로 썼다 (k6 도입, Actuator 도입, fixture, 로깅 조정).
- "4. 관측성": 미체크 4건(컨테이너 CPU/메모리, MySQL 지표, replica 지연, 스크레이프·보관)을 `선택 확장` 하위 목록으로 내렸다. 평소에는 k6 지표·앱 로그·DB 사후 검증을 남기고 이상이 관찰된 다음 지표를 본다는 원칙을 덧붙였다.
- Smoke 절: "3~5회 기준선" 을 삭제하고, 기본 1회 / 이상 의심 시 추가 실행 / 비교·threshold 조정 시 2~3회 탐색 측정으로 고쳤다. 전체 재실행 반복과 `order-race --rounds` 의 목적 차이를 적었다.
- "6. 단계 부하와 Soak", "CI 단계 > main/nightly" 제목에 `(선택 확장)` 을 붙였다.
- "완료 기준" 을 `기본` / `선택 확장` 두 절로 나눴다. 기본 9개 항목은 모두 충족 상태이며, nightly·지표 상관·기준선·포화점/soak·인덱스는 선택 확장으로 옮겼다.
- "현재 검증 범위와 제한" 에 문서 상태 구분(구현 완료 vs 선택 확장 미착수)과 과거 실측 기록의 성격을 적었다.
